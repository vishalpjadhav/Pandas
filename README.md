# 🐼 My Pandas Learning Journey

Welcome to my personal repository for mastering the Python **Pandas** library! This repository serves as my digital notebook and code laboratory where I practice data manipulation, cleaning, and analysis. 

Everything here is written inside interactive Jupyter Notebooks (`.ipynb`) as I learn and experiment with different Pandas functionalities.

---

## 🎯 Goal of this Repository
The purpose of this project is to build a strong foundation in Data Science by continuously pushing my practice codes, real-world mini-exercises, and syntax notes to GitHub.

---

## 📖 What I am Learning & Practicing

Inside my `.ipynb` notebooks, I am covering key concepts such as:

* **Pandas Basics:** Creating and managing Series and DataFrames.
* **Data Ingestion:** Reading data from various formats like CSV, Excel, and JSON.
* **Data Inspection:** Using `.head()`, `.tail()`, `.info()`, and `.describe()` to understand datasets.
* **Data Selection:** Filtering, slicing, and indexing data using `.loc[]` and `.iloc[]`.
* **Data Cleaning:** Handling missing values (`dropna()`, `fillna()`), removing duplicates, and changing data types.
* **Data Transformations:** Grouping data with `groupby()`, aggregating, sorting, and merging multiple DataFrames.
